Modularization, separation into modules (modular design / modular programming): break a system into cohesive and relatively independent units, each responsible for a well-defined aspect of the program's behavior.

Brief → Sketch → Studio → modularization.

Separation of Concerns (Separation of Responsibilities) is an architectural principle: each part of the system deals with a single "type of problem".
